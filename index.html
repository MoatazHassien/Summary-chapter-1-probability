Sample Space S🌐 فضاء العينة

فضاء العينة S = مجموعة كل النتائج الممكنة — مش بعضها، كلها كلها.

لازم تعرف إن في أي رمية، نتيجة واحدة بس هتحصل من نتائج S.

🎲
نرد عادي:
S = {1, 2, 3, 4, 5, 6}
🪙
عملة واحدة:
S = {H, T} = {ملك, كتابة}
Example 1.1 رمية عملتين معدنيتين
لو رمينا عملتين في نفس الوقت، وكل عملة ممكن تطلع وجه (H) أو كتابة (T) — إيه فضاء العينة؟
✅الحل

هنكتب كل النتائج الممكنة:

فضاء العينة كامل: S = { HH , HT , TH , TT }

كل نتيجة عبارة عن: (نتيجة العملة الأولى، نتيجة العملة التانية)

HH = الأولى وجه والتانية وجه
HT = الأولى وجه والتانية كتابة
TH = الأولى كتابة والتانية وجه
TT = الأولى كتابة والتانية كتابة
💡
مهم جداً — فضاء العينة بيتغير حسب اللي بتهتم بي يعني الترتيب جوا ال S مش بيفرق:
بعدد الوجوه مش بترتيبهم → S = {0, 1, 2}
يعني نفس التجربة، فضاءات عينة مختلفة حسب السؤال! يعني كام H و كام T
مثال 1.2 رمي عملة لحد ما يطلع وجه
نفضل نرمي عملة لحد ما يطلع وجه. إيه فضاء العينة؟
✅ الحل

ممكن يطلع وجه في أول رمية، أو في التانية، أو في التالتة... إلخ. فمعنى ده:

S = { H, TH, TTH, TTTH, ... }

أو لو اهتمينا بعدد الرميات فقط:

S* = { 1, 2, 3, 4, ... }

ده مثال على فضاء عينة لانهائي معدود infinite — النتائج لا نهائية لكن ممكن تعدها (1 و 2 و 3 ...).

مثال ١.٣ وقت حياة لمبة كهرباء
حطينا لمبة تشتغل لحد ما تحترق. إيه فضاء العينة؟
✅ الحل

اللمبة ممكن تتعطل في أي لحظة — يعني الوقت ممكن يكون أي رقم من 0 للانهاية:

S = { t : 0 ≤ t < ∞ }

ده فضاء عينة مستمر (Continuous) — لأن t بتاخد أي قيمة حقيقية مش بس أرقام صحيحة.

📏
لو قسنا الوقت بالساعة (أرقام صحيحة فقط):
S* = {0, 1, 2, 3, ...} → بقى فضاء عينة منفصل (Discrete)
🗂️ (متشغلش بالك بيهم دلوقتي لسة هناخدهم في شابتر 2) أنواع فضاء العينة
📦 منفصل (Discrete)

النتائج محدودة أو لانهائية معدودة.

مثال: نرد = {1,2,3,4,5,6} أو عدد الرميات = {1,2,3,...}

〰️ مستمر (Continuous)

النتائج بتاخد أي قيمة في فترة حقيقية — مش ممكن تعدها.

مثال: وقت الحياة، الحرارة، الضغط، الطول.

🎯Classical Probability
🎯 الاحتمال الكلاسيكي— أبسط طريقة لحساب الاحتمال
💡
الفكرة ببساطة:
لو التجربة عندها N نتيجة كلها متساوية الاحتمال ومتنافية، والحدث A فيه n(A) نتيجة منها — فاحتمال A ببساطة:
📐 القانون
P(A) = n(A) / N
= (عدد النتائج المحققة للحدث A) ÷ (إجمالي عدد النتائج الممكنة في S)
Ex 1.4 عملة تتقلب 3 مرات
نرمي عملة عادلة 3 مرات. عرّفنا:
A = الحدث إن وجهين أو أكتر بيطلعوا متتاليين
B = الحدث إن كل الرميات الثلاثة نفس النتيجة (كلها وجه أو كلها كتابة)
✅ الحل خطوة بخطوة

أولاً: نكتب فضاء العينة كامل:ال S

S = { HHH, HHT, HTH, THH, HTT, THT, TTH, TTT }

N = 8 نتيجة، كلها متساوية الاحتمال (لأن العملة عادلة) → احتمال كل نتيجة = 1/8

ثانياً: نحدد الحدث A (وجهين أو أكتر متتاليين):

HHH: وجه-وجه-وجه ✓ (الأول والتاني متتاليان)
HHT: وجه-وجه-كتابة ✓ (الأول والتاني متتاليان)
THH: كتابة-وجه-وجه ✓ (التاني والتالت متتاليان)
HTH, HTT, THT, TTH, TTT ✗ (مفيش وجهين متتاليين)
A = { HHH, HHT, THH } → n(A) = 3

ثالثاً: نحدد الحدث B (كلها نفس النتيجة):

B = { HHH, TTT } → n(B) = 2
P(A) = 3/8     P(B) = 2/8 = 1/4

A ∩ B = العناصر المشتركة = {HHH} فقط

P(A ∩ B) = 1/8

A ∪ B = {HHH, HHT, THH, TTT}

P(A ∪ B) = 4/8 = 1/4

Axiomatic Approach
ليه محتاجينه اصلا!! ؟؟؟
الاحتمال الكلاسيكي شغال كويس لكنه مش كافي لما النتائج مش متساوية (زي نرد معووج) أو لما فضاء العينة مستمر (زي الوقت). عشان كده Kolmogorov بنى الاحتمال على 3 حاجات رياضية.
⚡ الحاجات الثلاث — Kolmogorov's Axioms
  • I
    الاحتمال دايماً موجب أو صفر — مفيش احتمال سالب! (زي ال r في الديسكريت)
    P(A) ≥ 0 لأي حدث A
  • II
    احتمال فضاء العينة الكامل = 1 الحدث الأكيد
    P(S) = 1
  • III
    لو الأحداث متنافية، احتمال اتحادها = مجموع احتمالاتهم
    P(A₁ ∪ A₂ ∪ ...) = P(A₁) + P(A₂) + ...
    يعني لو A ∩ B = ∅ → P(A ∪ B) = P(A) + P(B)
Ex 1.7 ثلاثة خيول في سباق
3 خيول A و B و C في سباق.
A أكثر احتمالاً للفوز بضعف B.
B أكثر احتمالاً للفوز بضعف C.
إيه احتمال فوز كل منهم؟
✅ الحل

نفرض P(C) = p (الخيل الأصغر احتمالاً)

P(B) = 2p    (B ضعف C)
P(A) = 2×2p = 4p    (A ضعف B)

من البديهية II (مجموع الاحتمالات = 1 لأن واحد بس هيفوز):

4p + 2p + p = 7p = 1 → p = 1/7
P(A) = 4/7 ≈ 57%
P(B) = 2/7 ≈ 29%
P(C) = 1/7 ≈ 14%
✅
التحقق: 4/7 + 2/7 + 1/7 = 7/7 = 1 ✓
مثال ١.٨ نرد معووج (Loaded Die)

أوجد P(G) حيث G = رقم أكبر من 3 في رمية واحدة.
✅ الحل

P(1)+P(2)+P(3)+P(4)+P(5)+P(6) = 2p+p+2p+p+2p+p = 9p = 1
→ p = 1/9

Rules of Probability — نظريات مبنية على البديهيات
نظرية 1.1 — المجموعة الفارغة
P(∅) = 0

الحدث المستحيل احتماله صفر دايماً.
الإثبات: S ∪ ∅ = S و S ∩ ∅ = ∅ (متنافيان)
→ P(S) = P(S) + P(∅) → P(∅) = 0

نظرية 1.2 — المكمل ⭐
P(Ā) = 1 - P(A)

لأن A ∪ Ā = S (الأكيد) و A ∩ Ā = ∅ (متنافيان)
→ P(A) + P(Ā) = 1

🌟
حيلة ذهبية:
لو المطلوب صعب، احسب مكمله وطرح من 1!
نظرية 1.3 — المجموعة الجزئية
A ⊂ B → P(A) ≤ P(B)

لو A موجودة جوه B كاملاً، فاحتمال A مش ممكن يتعدى احتمال B.
المنطق: A جزء من B، فلازم أصغر منها أو تساويها.

نظرية1.4 — الحدود
0 ≤ P(A) ≤ 1

لأي حدث A في S، احتماله دايماً بين 0 و1 (شامل الاتنين).
يتبع من: ∅ ⊂ A ⊂ S → P(∅) ≤ P(A) ≤ P(S) → 0 ≤ P(A) ≤ 1

نظرية 1.5 — احتمال حدوث A وعدم حدوث B
P(A ∩ B̄) = P(A) - P(A ∩ B)

ده بيقولك: احتمال إن A يحصل لكن B مش يحصل = احتمال A ناقص احتمال إن الاتنين يحصلوا مع بعض.

📝
الإثبات ببساطة:
A = (A ∩ B̄) ∪ (A ∩ B) → اتحاد حدثين متنافيين
→ P(A) = P(A ∩ B̄) + P(A ∩ B)
→ P(A ∩ B̄) = P(A) - P(A ∩ B) ✓
⭐ نظرية 1.6 — قاعدة الجمع (Addition Rule) — الأهم في الفصل!
🌟 لأي حدثين A و B
P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
لو A و B متنافيان → P(A ∩ B) = 0 → P(A ∪ B) = P(A) + P(B)
❓
ليه بنطرح P(A ∩ B)؟
لأننا لما بنجمع P(A) + P(B)، بنحسب الجزء المشترك (A ∩ B) مرتين: مرة في P(A) ومرة في P(B). فلازم نطرحه مرة عشان نصحح الحساب.
📐
التعميم لـ 3 أحداث:
P(A∪B∪C) = P(A)+P(B)+P(C) - P(A∩B) - P(A∩C) - P(B∩C) + P(A∩B∩C)

نطبق قاعدة الجمع بتاعة نظرية 1.6:

P(M ∪ E) = P(M) + P(E) - P(M ∩ E)

نعوض بالأرقام:

0.9 = 0.75 + 0.85 - P(M ∩ E)

→ P(M ∩ E) = 0.75 + 0.85 - 0.9 = 0.7

🧮
احتمال الرسوب في الاتنين:
P(M̄ ∩ Ē) = 1 - P(M ∪ E) = 1 - 0.9 = 0.1
🧮
احتمال النجاح في واحدة بس:
= P(M ∪ E) - P(M ∩ E) = 0.9 - 0.7 = 0.2

Conditional Probability — عندك معلومة زيادة
💭
تخيل الموقف ده:
رمينا نرد P(طلع 4) = 1/6 عادي.
بس حد قالك "الرقم الطالع أكبر من 3" — دلوقتي فضاء العينة بتاعك تغير! بقى بس {4, 5, 6}.
→ P(طلع 4 | الرقم > 3) = 1/3 مش 1/6.
المعلومة الزيادة غيّرت الاحتمال!
تعريف ال Conditional Probability:
لو P(B) > 0، فاحتمال A بشرط إن B حصل بالفعل هو:
P(A|B) = P(A ∩ B) / P(B)
يُقرأ: "احتمال A بشرط B"

لو ضربنا الطرفين في تعريف الاحتمال الشرطي في P(B):

قاعدة الضرب لحدثين
P(A ∩ B) = P(A) · P(B|A) = P(B) · P(A|B)
📐
للـ 3 أحداث (الـ Corollary):
P(A ∩ B ∩ C) = P(A) · P(B|A) · P(C|A∩B)
Ex 1.12 والله ما اعرف يعني ايه انابيب تلفزيون بس قشطا مش مهم خلينا في السؤال ( أنابيب تلفزيون (بدون إرجاع)

التاني معيب بشرط الأول كان معيب: P(B|A) = 14/239 (بقى 239 أنبوب و 14 معيب)

1.7
🌳 الاحتمال الكلي ونظرية بايز
Total Probability & Bayes — إزاي تحسب لمايكون في Sample Space S كتير مش واحدة
📊 نظرية 1.8 — الاحتمال الكلي
💡
الفكرة:
لو الحدث A ممكن يحصل عن طريق أكثر من "سبب" (B₁ أو B₂ أو ... أو Bk)، بنحسب احتمال كل مسار ونجمعهم.

لو B₁, B₂, ..., Bk بيقسموا S (متنافيين واتحادهم = S):

قانون الاحتمال الكلي
P(A) = Σ P(Bᵢ) · P(A|Bᵢ)
= P(B₁)·P(A|B₁) + P(B₂)·P(A|B₂) + ... + P(Bk)·P(A|Bk)
Ex 1.14 شركة تأجير سيارات

الشركة 1: 60% من السيارات — 9% منها محتاجة صيانة
الشركة 2: 30% من السيارات — 20% منها محتاجة صيانة
الشركة 3: 10% من السيارات — 6% منها محتاجة صيانة
إيه احتمال إن أي سيارة وصلت للشركة هتحتاج صيانة؟
✅ الحل tree الاحتمالات
تطبيق الاحتمال الكلي
P(A) = (0.60)(0.09) + (0.30)(0.20) + (0.10)(0.06)
= 0.054 + 0.060 + 0.006 = 0.12

يعني 12% من كل السيارات هتحتاج صيانة.

🔮 1.9 — نظرية بايز (Bayes' Theorem)
الفرق بين الاحتمال الكلي وبايز:
الاحتمال الكلي: من الأسباب للنتيجة "إيه احتمال A؟"
بايز: من النتيجة للأسباب "بما إن A حصل، جه من أنهي مسار؟"
ده اللي بنسميه الاحتمال العكسي.
نظرية بايز
P(Bᵣ|A) = P(Bᵣ) · P(A|Bᵣ) / Σ P(Bᵢ) · P(A|Bᵢ)
r = 1, 2, ..., k    المقسوم عليه هو P(A) من الاحتمال الكلي
Ex 1.15 السيارة المتعطلة — جت من مين؟

= 0.060 / 0.120 = 0.5 = 50%

1.8
🔗 الأحداث المستقلة
Independent Events — لما حدث مش بيأثر في التاني خالص
💡
بكلام عادي:
A و B مستقلان لو حدوث أو عدم حدوث A مش بيغير من احتمال B خالص — والعكس بالعكس.
مثال: لو رميت عملة 3 مرات — نتيجة كل رمية مستقلة تماماً عن السابقة.
القانون بتاعنا :
A و B مستقلان إذا:
P(A ∩ B) = P(A) · P(B)
لو الشرط ده مش محقق → A و B مترابطان (Dependent)
🔑
علاقة بConditional Probability
لو A و B مستقلان : P(A|B) = P(A)   و   P(B|A) = P(B)
يعني معرفتك إن B حصل مش بتغير احتمال A.
Ex 1.17عملة 3 مرات و عايز يعرف Dependent ولا لا
عملة عادلة اتقلبت 3 مرات:
A = وجه في أول رميتين = {HHH, HHT}
B = كتابة في الرمية الثالثة = {HHT, HTT, THT, TTT}
C = بالظبط 2 كتابة في الـ3 رميات = {HTT, THT, TTH}
a) هل A و B مستقلان؟     b) هل B و C مستقلان؟
✅ الحل
S = {HHH, HHT, HTH, THH, HTT, THT, TTH, TTT} → N = 8
🔢
نحسب الاحتمالات الأساسية:
P(A) = 2/8 = 1/4    P(B) = 4/8 = 1/2    P(C) = 3/8
A ∩ B = {HHT} → P(A ∩ B) = 1/8
B ∩ C = {HTT, THT} → P(B ∩ C) = 2/8 = 1/4
✅
a) A و B مستقلان:
P(A) × P(B) = 1/4 × 1/2 = 1/8
P(A ∩ B) = 1/8
الاتنين متساويان → مستقلان ✓
❌
b) B و C مترابطان:
P(B) × P(C) = 1/2 × 3/8 = 3/16
P(B ∩ C) = 1/4 = 4/16
3/16 ≠ 4/16 → مترابطان ✗
📌 inDependent ل 3 أحداث أو أكتر

لـ 3 أحداث A, B, C نقول إنهم مستقلين لو كل الشروط دي اتحققت:

P(A∩B)=P(A)·P(B)    P(A∩C)=P(A)·P(C)    P(B∩C)=P(B)·P(C)
P(A∩B∩C) = P(A) · P(B) · P(C)
⚠️
تحذير مهم جداً:
ممكن كل اتنين مستقلين (Pairwise Independent) لكن الـ3 مع بعض مش مستقلين. لازم تتحقق كل الشروط الأربعة.
🎲
without replacement ..v.s.. with replacement :
مع الإرجاع (with replacement):
كل سحبة مستقلة عن التانية ( Independent)
P(3 معيبين من 20، فيهم 5 معيبين)
= (5/20)³ = (1/4)³ = 1/64
بدون إرجاع (without replacement):
الأحداث مترابطة ( Dependent)

= (5/20)(4/19)(3/18) = 1/114
